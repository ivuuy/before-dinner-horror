# 晚饭之前 · Before Dinner

一个 Godot 4.5 第一人称恐怖游戏原型。玩家在雨夜老宅里完成一条短逃生链：

1. 去卧室书桌拿起搪瓷碗。
2. 到餐桌空位摆碗。
3. 打开客厅电视，把奶奶引开。
4. 趁厨房暂时空下来拿走铁盒里的钥匙。
5. 回到大门逃走。

## 运行

安装 Godot 4.5 或更新版本后，打开项目目录并运行 `project.godot`。鼠标进入游戏后会被捕获。

操作：WASD 移动，Shift 奔跑，Ctrl 蹲下，鼠标观察，E 互动，Esc 释放鼠标，结局画面按 R 重开。

工程中的几何体、材质和雨窗效果由代码生成，方便继续替换成 Blender / GLB 资产。入口场景是 `scenes/main.tscn`，核心流程在 `scripts/main.gd`。
